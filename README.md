# Dragon's Dream

Dragon's Dream is a browser game about raising dragons. You explore five gentle realms, make friends with wild dragons, practice duels, and look after your companions at Dreamhold Castle.

The game lives in one file. It does not ask you to sign in. While you play, it stays on your device and does not send anything over the internet.

## How to play

Play it here, once GitHub Pages is turned on for this repository:

https://simoncarignan-bot.github.io/dragons_dream/

You can also download `index.html` and open that file in Safari, Chrome, or another browser. It works with no internet.

- On the first screen, start a new adventure or continue one you already saved.
- Tap the map to walk. You can also use the arrow buttons or the arrow keys.
- Cyan wild dragons can become friends with your leash. Red markers are practice battles.
- Feed your dragons so they grow: Baby, then Young at level 3, then Adult at level 6.
- Dreamhold Castle is home. Rest there, visit the stable, and decorate.
- Tap **Save**. Your world stays in this browser on this device.

A grown-up can open **Grown-ups** to copy a Save code, or to bring a saved world back.

## Changing the game with an AI helper

You can change the game with an AI helper such as Claude, Gemini, or Cursor.

1. Open this repository in the helper.
2. Describe the change in plain words. For example: "Add a purple flower in the meadow" or "Make the Save button easier to see on an iPad."
3. Test the game in a browser.
4. When it looks right, commit the change. The commit message should say what changed, in plain words.

The whole game is `index.html`. Helpers should follow the rules in `AGENTS.md`.
